# Six-week implementation plan

| Week | Focus | Required deliverable |
|---|---|---|
| 1 | Frozen CBT knowledge-base RAG | Clean corpus, hybrid retrieval, reranker, 50-query evaluation, notebook and report |
| 2 | Memory schema and short-term state | Pydantic/JSON schemas, session state, thought records, assignment state and provenance |
| 3 | Long-term memory manager | Candidate extraction, fact/inference separation, deduplication, persistence and retrieval |
| 4 | Lifecycle and user control | Conflict/update logic, expiration/forgetting, confirm/edit/delete APIs and UI |
| 5 | Agent and application integration | Journal/chat, assignment page, memory page, phase summary and deterministic safety diversion |
| 6 | Multi-session evaluation | Three memory conditions, synthetic/de-identified cases, accuracy/consistency/safety/latency/cost report |
