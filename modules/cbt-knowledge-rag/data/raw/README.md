# Local source documents

Historical pilot filenames are now recorded in `source_registry.json`. None is currently approved for retrieval. Only place and enable a document after its exact identity, usage rights and SHA-256 have been reviewed and recorded there.

PDFs are intentionally excluded from Git because public availability or purchase does not automatically grant redistribution rights. An official sample is not automatic RAG permission either. Local retrieval, external model transmission and corpus redistribution require independent registry approvals.
