# Memory schema

Define typed records for:

- explicit user facts and preferences;
- episodic events;
- emotions and situations;
- goals and CBT assignments;
- assignment outcomes;
- candidate and confirmed cognitive patterns;
- user corrections;
- restricted safety-related information.

Every record must retain provenance, created/observed/updated timestamps, confidence, user-confirmation state, lifecycle status and sensitivity. Explicit user statements and model inferences must use different record types or flags.
