# Independent judge calibration

This hosted Colab entry point evaluates the new Qwen-family judge against the
existing TherapyJudgeBench v2 published expert labels. It preserves the original
nine-aspect CTRS and four safety scoring code. R1 factual continuity and R3
next-step memory judgments require their own source checks.

The bank is pinned to commit
`fba2e5ad29356417cde50479d823c6cf0b316754`, 1,446,326 data bytes and SHA-256
`ade12985a5224e425805cfb198b3a3fa338727a158f1446fa5073a40fdf6fd01`.
Acquisition and real record loading require genuine hosted Colab. The 116 source
dialogues remain intact. Records generated by a Qwen therapist are excluded from
this different-family judge comparison and their IDs and reason are frozen.

Every other released dialogue is projected to visible speaker/content fields.
Expert ratings, hidden case profiles and model identifiers stay outside the
model request. Exact published profile IDs provide grouping labels. Higher-level
source-family lineage is unavailable, so this adapter reports that limitation
and makes no family-disjoint holdout claim. The fixed prompt is evaluated without
tuning it against these labels. Ten percent of planned primary items are repeated
as independent sends. The finite maximum is calculated from the complete grid.

The requested judge is `qwen3.5-plus` and the required returned model is
`qwen3.5-plus-2026-04-20`. The shared architecture journal sends the frozen payload
verbatim, records exact wire hashes and prevents automatic replay of unknown
attempts. This preserves the alias mapping explicitly.

Run from the pinned checkout in hosted Colab.

```bash
python evaluation/architecture-calibration/run_calibration.py acquire \
  --bank /content/cbt-v4-calibration-bank
python evaluation/architecture-calibration/run_calibration.py prepare \
  --bank /content/cbt-v4-calibration-bank --output /content/cbt-v4-calibration
python evaluation/architecture-calibration/run_calibration.py run \
  --output /content/cbt-v4-calibration
```

The run command uses the already-authorized `Capstone` Colab Secret in the hosted
kernel. It prints only execution status. Native judgments, usage and per-dimension
agreement are retained in the run directory. Monetary charges remain unknown
unless separately reconciled with billing records.
